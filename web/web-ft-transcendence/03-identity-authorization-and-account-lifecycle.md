## 1. 개발 스레드 목표

등록 사용자 세션이 저장소에 처음 저장되는 시점부터 HTTP 로그인/로그아웃에 연결되고, 클라이언트 측 쿠키 삭제만으로는 끝나지 않던 로그아웃이 서버 측 권한 회수로 수정된 뒤, 인증 모델 변경 시 기존 세션만 안전하게 만료하는 마이그레이션으로 마무리되는 과정을 복원합니다.

이 문서는 정확한 SHA를 순서대로 확인해 설계 → 구현 → 실패 → 수정 → 검증 과정을 복원합니다.

### 직접 연결되는 불변 조건

- 등록 사용자 세션의 생성·조회·폐기는 `AppRepository`가 소유합니다.
- 로그아웃 이후 동일한 서버 세션 인증 정보는 다시 인증에 성공하지 않아야 합니다.
- 인증 마이그레이션은 기존 세션을 폐기하되 사용자·경기·레이팅 이력을 변경하지 않아야 합니다.

## 2. 핵심 질문

- PostgreSQL과 메모리 저장소가 세션 신원을 각각 어디에 저장하며 만료를 어떻게 판단합니까?
- 초기 로그아웃이 쿠키만 지웠을 때 Bearer/쿼리 인증 정보가 계속 유효했던 이유는 무엇입니까?
- `readSessionToken`과 `deleteSession`이 어떤 순서로 호출되며 DB 삭제 실패 시 응답은 어디까지 진행됩니까?

#### 최소 코드 근거

- SHA: `252befef9527`


## 9. 개발 스레드 최종 상태

### 최종 소유 주체

등록 세션의 판정 기준 상태는 저장소입니다. HTTP 계층은 토큰을 전달하고 로그인/로그아웃 명령을 조정하며, 마이그레이션 계층은 신뢰 모델 변경 시 기존 인증 정보를 일괄 폐기합니다.

### 최종 실행 순서

로그인에서 사용자 업서트와 세션 생성 후 쿠키를 설정합니다. 인증 요청은 저장소가 토큰을 현재 사용자로 해석합니다. 로그아웃은 제시된 토큰을 저장소에서 먼저 삭제하고 쿠키를 지웁니다. 인증 계약 전환 시 005 마이그레이션이 남은 기존 sessions를 전부 제거합니다.

### 최종 보장 범위

성공한 로그아웃 토큰의 재사용 차단과, 005 적용 시 모든 PostgreSQL 기존 세션 폐기 및 핵심 영속 기록 보존이 코드와 회귀 테스트로 연결됩니다.

### 최종적으로 보장하지 않는 범위

사용자의 모든 기기에서 로그아웃하는 기능, 세션 행의 TTL 정리, DB 삭제와 클라이언트 쿠키 삭제의 분산 원자성, 온라인 마이그레이션의 무중단성은 이 개발 스레드가 보장하지 않습니다.

### 최종 실행 순서

사용자는 일반 로그인으로 `user` 역할의 세션을 얻습니다. 별도 저장소 연산과 CLI만 NPC가 아닌 사용자의 역할을 변경합니다. 관리자 요청은 현재 사용자를 조회한 뒤 미인증 사용자, 정지된 사용자, 관리자가 아닌 사용자를 차례로 거부하고, 모두 통과한 경우에만 처리 함수가 저장소 연산을 호출합니다.

### 최종 보장 범위

핸들 기반 권한이 제거되고, 명시적 역할 할당과 활성 상태 상태를 반영하는 관리자 권한 검사가 PostgreSQL/API 회귀로 보호됩니다.

### 최종적으로 보장하지 않는 범위

역할 변경 감사·approval, CLI 호출자 인증, 역할 변경과 활성 세션의 즉시 강제 로그아웃, 이미 열린 실시간 연결 회수는 이 개발 스레드 범위 밖입니다.

## 9. 개발 스레드 최종 상태

### 최종 소유 주체

저장소 트랜잭션이 영속 상태와 감사 레코드를 소유하고, API가 새 HTTP/WS 권한을 판정하며, GameHub가 이미 열린 현재 실시간 연결과 관련 메모리 자원을 회수합니다.

### 최종 실행 순서

활성 관리자 요청이 차단을 요청하면 저장소 트랜잭션이 대상 상태와 감사 동작을 함께 커밋합니다. 차단인 경우 처리 함수가 `GameHub.revokeUser`를 호출해 현재 클라이언트의 타이머, 버퍼, 소속 정보, 인덱스, 입력 상태를 해제하고 경기방 측을 예약한 뒤 소켓을 4003으로 닫습니다. 이후 같은 세션의 새 티켓 요청은 현재 정지 여부 상태 때문에 403입니다.

### 최종 보장 범위

정상 단일 프로세스 경로에서 감사 없는 부분 반영 차단을 막고, 보호된 HTTP/WS 참가와 이미 열린 서버가 확정하는 연결을 모두 차단하는 회귀 증거가 연결됩니다.

### 최종적으로 보장하지 않는 범위

DB 커밋과 메모리 권한 회수의 분산 원자성, 여러 인스턴스 연결 전파, 종료 프레임 전달, 프로세스 비정상 종료 직후 자동 보상은 이 개발 스레드가 보장하지 않습니다.
